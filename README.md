# ZCMU Schedule v2 + 2 Pages

This is the original ZCMU Schedule v2 UX/UI with **two additional pages only**:

- `index.html` — existing class schedule page (kept as the main page)
- `timeline.html` — university academic timeline, including the provided 2026–2027 calendar image
- `study.html` — nightly study plan 19:30–23:30, linked to the class schedule data

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages

Upload the whole `zcmu-schedule` folder to a GitHub repository and enable GitHub Pages from the `main` branch / root folder.

No backend, database, API, or external runtime is required.

## Important calendar rule

Week 1 starts on **14 September 2026**, matching the user's academic calendar and the corrected schedule logic.
