# Schedule data

`schedule.js` คือข้อมูลที่แปลงจาก Excel แล้วสำหรับเว็บโดยตรง

- `periods` = ตารางเวลา 1–13 ของ富春校区
- `courses` = รายวิชาและ occurrence แยกตามวัน/สัปดาห์/คาบ
- `d`: 1 จันทร์ ... 7 อาทิตย์
- `w`: ช่วงสัปดาห์ เช่น `1-2,5-10`
- `p`: คาบ เช่น `[3,4]`

แก้ไฟล์นี้ได้โดยตรงจาก VS Code แล้ว refresh เว็บ
